# Snipe Outbound — Landing Page

High-converting landing page for Snipe Outbound, a B2B cold email lead generation agency.

## Tech Stack
- Static HTML/CSS/JS (no build step required)
- Google Fonts (Manrope, Inter)
- Vanilla JavaScript for interactions

## Deploy
This site can be deployed to any static hosting:
- **Vercel**: `vercel deploy`
- **Netlify**: drag & drop the folder
- **GitHub Pages**: enable in repo settings

## Structure
```
├── index.html      # Main page
├── css/style.css   # All styles
├── js/main.js      # Interactions & animations
└── assets/         # Images (add your own)
```

## Customization
- Update `cal.com` links to your actual booking link
- Add your Snipe logo to `assets/` and reference in HTML
- Replace placeholder pricing with actual pricing
